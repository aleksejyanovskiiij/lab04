## Содержание работы

### Часть 1 - `main1.py` (данные Пренатальная диагностика)

Анализ набора данных о новорождённых и их матерях:

1. Загрузка данных в `DataFrame` и подсчёт числа мальчиков и девочек.
2. Добавление столбца **ИМТ** (индекс массы тела): `ИМТ = масса / рост**2`.
3. Расчёт числовых характеристик всех показателей (среднее, медиана, размах, асимметрия, эксцесс и т.д.).
4. Проверка всех показателей на **нормальность** тремя способами:
   - гистограмма с кривой KDE и наложенной нормальной кривой (визуальная оценка);
   - коэффициенты асимметрии и эксцесса;
   - критерий **Шапиро–Уилка** (уровень значимости alpha = 0.05).
5. Проверка **гендерных различий** роста, веса и ИМТ новорождённых:
   - предварительная проверка нормальности по **Шапиро–Уилку**;
   - критерий **Ливена** для выбора между t-критерием Стьюдента (равные дисперсии) и t-критерием Уэлча (разные дисперсии);
   - **t-тест** для сравнения средних мальчиков и девочек.

**Статистическая модель.** Поскольку объёмы групп достаточно велики, в силу **центральной предельной теоремы** применение t-теста корректно даже при отклонении данных от нормального распределения.

### Часть 2 - `main2.py` (данные Психологи)

Сравнение психологических и учебных показателей юношей и девушек:

1. Загрузка данных и подсчёт числа юношей и девушек.
2. Для каждого из 15 показателей (субтесты интеллекта, средний IQ, экстраверсия/интроверсия, нейротизм, средняя отметка):
   - проверка нормальности по **Шапиро–Уилку**;
   - критерий **Ливена** о равенстве дисперсий;
   - выбор t-критерия **Стьюдента** или **Уэлча**;
   - **t-тест** средних и расчёт **размера эффекта d Коэна**.
3. Ранжирование показателей по модулю t-статистики и вывод показателя с сильнейшими и слабейшими гендерными различиями.

### Бонус - `main_bonus.py` (данные Iris)

Проверка показателей цветков ириса на нормальность с помощью критерия **хи-квадрат Пирсона**:

1. Загрузка набора данных Iris (150 наблюдений, 4 признака: длина/ширина лепестка и чашелистика).
2. Для каждого признака строится функция `gauss()`, которая:
   - выводит среднее, медиану, асимметрию и эксцесс;
   - группирует данные в равновероятные интервалы и сравнивает наблюдаемые частоты с ожидаемыми для нормального распределения (критерий **хи-квадрат Пирсона**, alpha = 0,05);
   - строит гистограмму с KDE и нормальной кривой.
3. Находится самый ненормальный показатель (с минимальным p-значением) и проверяется на нормальность отдельно для каждого сорта ириса.

Ключевой вывод: внутри каждого сорта признаки распределены нормально, но при объединении сортов в одну выборку нормальность нарушается, так как смешиваются несколько генеральных совокупностей с разными средними.

## Результаты

- Часть 1: установлено, какие антропометрические показатели новорождённых отклоняются от нормального распределения и по каким параметрам (рост, вес, ИМТ) наблюдаются статистически значимые гендерные различия.
- Часть 2: для каждого из 15 показателей получены p-значения t-теста и размер эффекта d Коэна; построен рейтинг показателей по силе гендерных различий.
- Бонус: показатели ирисов проверены на нормальность; показано, что смешение разных сортов разрушает нормальность выборки.

## Замечания

- Все выводы принимаются на уровне значимости alpha == 0.05.
- Критерии (Стьюдент или Уэлч) подбираются автоматически на основании критерия Ливена о равенстве дисперсий.
- Скрипты выводят подробные текстовые отчёты в консоль, а части 1 и 3 дополнительно строят гистограммы (`plt.show()`).
